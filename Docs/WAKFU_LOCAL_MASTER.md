# Local master catalog integration (Wakfu V05)

The master SQLite stays local. Generate a lightweight JSON projection from its classes and playable_class_spells view; package only the projection and its manifest alongside the executable locally, not on GitHub. The manifest checksum covers the projected JSON (not the source SQLite); source version and provenance are supplied by the local export. Restart to reload. If the local catalog directory is present, no legacy spell alias, class mapping or cost fallback is used, even on rejection. If absent, legacy behavior is retained with a warning. Ambiguous spell names yield no class or cost unless all active rows agree on the respective value; passives do not infer cast metadata. Costs are exported base PA, not effective costs. No changes to observed damage calculations. Breed IDs are client export IDs; validate against real combat logs before treating log namespace correspondence as confirmed. Existing UI icons are unchanged and may not cover new classes. The local projection is not uploaded with CI artifacts. Build artifact is a framework-dependent Windows x64 folder, not an installer or release. It may use existing AppData and updater; do not run alongside the installed instance.
